# ==============================================================================
# Passwordless SSH and Sudo Setup for SonoRo Swarm
# ==============================================================================

Step 1: Set up passwordless SSH (requires password once)
-------------------------------------------------------
    python fleet_manager.py \
      --ips-file robots.txt \
      --setup-ssh \
      --key-file ~/.ssh/id_ed25519_sonoro_fleet

This will generate a dedicated SSH key, copy it to all robots in parallel, and enable passwordless SSH access.


Step 2: Set up passwordless Sudo (requires sudo password once)
-------------------------------------------------------------
    python fleet_manager.py \
      --ips-file robots.txt \
      --setup-sudo

This connects to each robot, prompts for your sudo password once, and configures `/etc/sudoers.d/010_nopasswd` so that privileged fleet operations (like setting udev permissions and syncing hardware clocks) run without blocking for a password.


Manual Sudo Configuration (on a single Raspberry Pi):
-----------------------------------------------------
    echo "$USER ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/010_nopasswd
    sudo chmod 0440 /etc/sudoers.d/010_nopasswd
